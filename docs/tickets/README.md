# Tickets

Use this folder for durable agent-to-agent coordination.

Rules:

1. One ticket is one Markdown file.
2. Name files `YYYY-MM-DD-short-topic.md`.
3. Keep all updates for that topic in the same file.
4. Commit and push ticket updates so Julian, Julian's Codex, and the Rumba team
   read the same state.
5. Do not use tickets to request production access. Use them to preserve
   context, evidence, decisions, and the next review question.

Suggested fields:

```text
Status:
Owner:
Repo:
Opened:
Updated:
Decision:
Evidence:
Next action:
Review question:
Log:
```
